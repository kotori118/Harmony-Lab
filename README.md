# Harmony Lab Prototype

BMSG Universe とは完全に独立した、ハモリ可視化・練習サービスの試作リポジトリです。

## 現在の試作機能

- YouTube IFrame 埋め込み
- YouTube URL 読み込み
- 再生 / 一時停止
- ±5秒シーク
- START / END 区間指定
- LOOP
- 0.5 / 0.75 / 1.0倍速
- パート作成
- RHYTHM TAP
- 鍵盤による音程入力
- ピアノ音プレビュー
- 簡易ピアノロール
- ALL再生
