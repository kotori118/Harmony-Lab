# Harmony Lab Prototype

BMSG Universe とは独立した、ハモリ可視化・練習サービスの試作リポジトリです。

## 現在の試作機能
- 日本語UI
- YouTube参考音源（譜面・収録とは非同期）
- 1曲1BPM設定 / メトロノーム
- BPM吸着なしのリズム収録
- 区間ごとに独立した譜面
- 4拍固定カウントイン
- 任意位置から収録開始
- タップ / 長押しで音の開始位置・長さを記録
- 同一メンバーの複数パート
- 主旋律 / ハモリの表示・再生切替
- 複数パートを鳴らしながら別パートを収録
- パート全体 / 選択部分のリズムコピー
- 鍵盤で音程登録・実音確認
- 登録済み音程の譜面再生
- 中央固定再生ライン + BPM連動スクロール
- 小節線
- ノート移動 / 長さ変更 / 分割 / 削除

## 現段階では未実装
- Universe連携
- スプレッドシート保存
- 歌詞データ連携
- 永続保存 / 読み込み

## 方針
現段階では BMSG Universe / BMSG-PJ / BMSG-DB / 正式仕様書には変更を加えません。独立プロトタイプで操作感を確認してから正式設計へ反映します。
